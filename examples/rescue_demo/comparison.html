    How AURA produces the JSON
    
    Original video → Frame sampling → CLIP visual features → Activity classification → Verb–noun action scoring → Temporal refinement (opt-in) → Highlight selection → Structured JSON.
    
    
    The stock scorer pools roughly two seconds of evidence at 2 frames per second and can merge adjacent detections of the same pair. The opt-in scorer uses one-second strides and may trim accepted intervals. Highlight importance uses visual evidence and activity relevance, plus action confidence for overlapping samples. Both arms use the same highlight planner. The local comparison measured end-to-end outputs.
